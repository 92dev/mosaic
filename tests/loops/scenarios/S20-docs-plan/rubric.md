# Documentation task-class rubric
1. Are both documentation tasks executed within their disjoint files, with every new statement cited to actual source lines and no code or decision change?
2. Is the out-of-range source request narrowed before dispatch or reported by a clean executor STOP, never retained as a nonexistent citation?
3. Does each docs task wave use exactly one cross-family reviewer selected from the resolved executor role, while the closure packet receives the full pair and findings retain task/round/reviewer attribution?
4. Do shared lint/doctor/checkup gates run after parallel executors join, and does the orchestrator—not an executor—own close-out bookkeeping?
5. Does the whole sign-off brief fit within 40 lines, disclose evidence limits and remaining defects without false completion claims, and stop without landing?
