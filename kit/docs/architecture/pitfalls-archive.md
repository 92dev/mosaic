# Pitfalls Archive (retired P-x)

Each entry keeps its original text and adds `**Archived:** <what superseded or disproved it, or which landed plan removed its subject>`. Numbers are never reused; citations of a retired pitfall still resolve here.
Read [registries](../process/registries.md) before consulting archived history; report hits as `archived:`, never as a current trap.
